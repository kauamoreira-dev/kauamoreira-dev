## Projetos

### Vagas Tapajós

Plataforma de vagas de emprego de Santarém e da região do Tapajós. Reúne candidatos e empresas: publicação de vagas, candidaturas e perfis, com interface pensada para o celular.

React · Vite · Supabase (autenticação e banco de dados)<br>
[vagastapajos.com.br](https://vagastapajos.com.br) · em produção · código privado

### Currículo Tapajós

Gerador de currículos gratuito e sem cadastro. Editor com prévia da folha A4 em tempo real, três modelos, estimativa de páginas e PDF pela impressão do navegador. Os dados ficam só no aparelho, com backup em arquivo e tratamento de conflito quando o mesmo currículo está aberto em duas abas.

React · Vite · CSS Modules · Vitest · Testing Library · Playwright · GitHub Actions<br>
[Demo](https://curriculo-tapajos.vercel.app) · [Código](https://github.com/kauamoreira-dev/vagas-curriculo)

### DevPath

Painel de carreira e prospecção para dev freelancer. Busca empresas reais por cidade e segmento, organiza um funil de abordagem com follow-ups, gera propostas em PDF e publica uma página de serviços. Funciona como app instalável e offline.

JavaScript sem framework · Supabase (Auth, Postgres com RLS, Edge Functions em Deno) · PWA<br>
[Demo](https://devpath-sand.vercel.app) · [Código](https://github.com/kauamoreira-dev/devpath)

### Moreira | Sites & Sistemas

Site institucional de um estúdio de desenvolvimento web: serviços, processo de trabalho, projetos e perguntas frequentes, com animações leves e barra de ações fixa no celular.

React · TypeScript · Vite · Framer Motion · CSS Modules<br>
[Demo](https://moreira-sites-sistemas.vercel.app) · [Código](https://github.com/kauamoreira-dev/moreira-sites-sistemas)
